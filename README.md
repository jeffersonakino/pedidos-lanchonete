# Pedidos da Lanchonete

Aplicacao para organizar pedidos de retirada no balcao de uma lanchonete.

## Escopo inicial

- Cadastrar pedidos com nome do cliente, itens, quantidades e observacoes.
- Consultar pedidos e filtrar por status.
- Atualizar o status entre recebido, em preparo e pronto.
- Exibir um resumo dos pedidos por etapa.

## Fora do MVP

- Login e gerenciamento de usuarios.
- Pagamento online.
- Entrega.

## Desenvolvimento

As telas, tecnologias e persistencia de dados serao definidas antes da implementacao.
